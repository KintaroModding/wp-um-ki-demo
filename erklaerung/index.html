Schritt 1 · Kurz

WordPress und Plugins

WordPress ist das Fundament. Plugins sind Bausteine, die neue Funktionen hinzufügen.

Ihre WebsiteDas, was Besucher sehen und nutzen
ThemeAussehen und Aufbau der Seiten
Plugins Zusätzliche Funktionen
Ultimate Member Shop Veranstaltungen SEO …
InhalteSeiten, Beiträge, Bilder
WordPress-KernVerwaltung, Benutzer, Rechte, Schnittstellen
DatenbankHier wird fast alles gespeichert

Wichtig für heute: Ultimate Member ist so ein Plugin. Fast alles, was es tut, steht in der Datenbank – nicht in Dateien. Das ist der Schlüssel für Kapitel 3 und 4.

Gut zu wissen: Die Felder der Formulare stehen in einem kompakten Spezialformat in der Datenbank. Man ändert sie deshalb sicherer über Werkzeuge als direkt in der Datenbank. Genau das übernimmt der KI-Agent.

Hauptweg

MCP

Model Context Protocol
Was ist das?
Ein offener Standard, über den KI-Agenten die Werkzeuge einer Website direkt nutzen. Die Website bietet „Fähigkeiten“ an, der Agent ruft sie auf.
Stärke
Für KI gebaut. Klar festgelegte Aktionen. Rechte genau steuerbar.
Braucht
Ein MCP-Plugin und einen Zugang mit Anwendungspasswort.

REST API

Programmier-Schnittstelle über das Internet
Was ist das?
In jedes WordPress eingebaut. Programme lesen und ändern darüber Inhalte und Benutzer.
Stärke
Immer vorhanden. Gut für Inhalte, Benutzer und Shop-Daten.
Braucht
Einen Zugang mit Anwendungspasswort.

WP-CLI

Kommandozeile für WordPress
Was ist das?
Befehle, die direkt auf dem Server laufen. Das Werkzeug der Profis.
Stärke
Sehr mächtig: Einstellungen, Plugins, Updates, Backups, Datenbank.
Braucht
SSH-Zugang beim Hosting.
MCPREST APIWP-CLI
Für KI-Agenten gebaut ja teilweise teilweise
Ultimate Member einstellen ja, mit passenden Fähigkeiten eingeschränkt ja
Updates und Backups – – ja
Braucht Server-Zugang nein nein ja (SSH)

Unser Ansatz: MCP als Hauptweg, WP-CLI für alles Technische, die REST API als Ergänzung. Aktuelle WordPress-Versionen bringen die Grundlage für MCP schon mit – auf Ihrer Seite ist ein MCP-Zugang bereits zu sehen. Fehlt eine Fähigkeit, ergänzen wir sie.

Schritt 5

Der sichere Ablauf jeder Änderung

Jede Änderung geht denselben festen Weg. Der KI-Agent arbeitet schnell – aber nie allein und nie direkt auf der Live-Seite.

  1. Ihr Team Wunsch Die Änderung wird in normalen Worten beschrieben.
  2. KI-Agent Umsetzung auf der Testseite Der Agent baut die Änderung auf einer Kopie der Website. Die Live-Seite bleibt unberührt.
  3. Mensch Prüfung Ein Mensch prüft das Ergebnis und den Code.
  4. Sie Freigabe Sie sehen die Änderung auf der Testseite und geben grünes Licht.
  5. KI-Agent + Mensch Live schalten Erst ein Backup, dann dieselbe Änderung auf der Live-Seite.
  6. Falls nötig Rückweg Passt etwas nicht, ist der alte Stand in Minuten zurück.
Für Sie ergänzt

Wöchentlicher Prüfbericht

Jede Änderung wird protokolliert. Einmal pro Woche fasst die KI alles in einem Bericht zusammen.

  • Was, wann, warum – und wer es freigegeben hat
  • Auffälliges ist markiert, z. B. ungewöhnlich viele Änderungen an einer Stelle
  • Der Bericht geht an Sie oder eine Person, die Sie bestimmen
  • Sie bestätigen ihn mit einem Klick – das ist Ihr finaler Audit
